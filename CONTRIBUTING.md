# contributing

Issues and pull requests are welcome.

## tests

```sh
python -m unittest discover -v
```

## guidelines

- keep runtime dependencies at zero
- keep the CLI usable on Termux and desktop systems
- update `README.md` and the translations when behavior changes
- include the OS, Python version, command, and output in bug reports

## translations

The current translations are Russian, Spanish, and Simplified Chinese. If you add a language, add a link to the language selector in every README file.
