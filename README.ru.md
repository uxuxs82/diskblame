# diskblame

![ci](https://github.com/uxuxs82/diskblame/actions/workflows/ci.yml/badge.svg)

[english](README.md) | [русский](README.ru.md) | [español](README.es.md) | [中文](README.zh-CN.md)

`diskblame` хранит лёгкую историю использования диска и показывает, что изменилось.

`du` и `ncdu` показывают текущее состояние. `diskblame` складывает снапшоты метаданных в SQLite, поэтому можно спросить, что выросло с прошлой недели, какой каталог виноват и почему файл всё ещё лежит.

Он не копирует файлы.

## почему не просто du?

`du` и `ncdu` отвечают на вопрос "что занимает место сейчас". Они не отвечают на вопрос "что выросло за неделю", если не хранить полные копии или не запоминать цифры. `diskblame` хранит несколько чисел на путь и сравнивает их позже.

Инструмент сделан для случая, когда место уже кончается: телефон, маленький vps или ноутбук с полным диском. База хранит только метаданные, поэтому снапшот каталога на 100 гиб обычно занимает несколько мегабайт.

| инструмент | хранит историю | объясняет путь |
| --- | --- | --- |
| `du`, `ncdu` | нет | нет |
| `duc` | индексированное текущее состояние | нет |
| `snapdiff` | сравнивает два дерева | нет |
| `diskblame` | снапшоты метаданных | `diff` и `why` |

## установка

Нужен python 3.11 или новее. Зависимостей нет.

```sh
pipx install git+https://github.com/uxuxs82/diskblame.git
```

Или из локальной копии:

```sh
git clone https://github.com/uxuxs82/diskblame.git
cd diskblame
pip install .
```

На Termux:

```sh
pkg install python
pip install .
```

## быстрый старт

```sh
diskblame snap ~
diskblame snap ~
diskblame diff --since 7d
```

Первый снапшот это база для сравнения. Второй даёт `diff`, с чем сравнивать.

Показать самые большие каталоги:

```sh
diskblame top --depth 2
```

Показать самые большие файлы:

```sh
diskblame top --files --limit 30
```

Объяснить файл:

```sh
diskblame why ~/storage/shared/DCIM/Camera/IMG_0001.jpg
```

`why` показывает размер, тип, возраст, git-статус, дубликаты, ссылки в соседних текстовых файлах и то, похож ли путь на кеш или каталог сборки. Он не утверждает, что файл безопасно удалять. Он даёт факты и осторожный вывод.

## команды

| команда | что делает |
| --- | --- |
| `snap [path]` | сканирует каталог и сохраняет снапшот |
| `diff` | сравнивает два снапшота, по умолчанию последние два |
| `top` | показывает самые большие каталоги или файлы в снапшоте |
| `why <path>` | объясняет файл или каталог |
| `chart` | показывает общий размер во времени |
| `watch` | предупреждает, когда каталог вырастает выше лимита |
| `prune` | удаляет старые снапшоты |
| `config` | показывает или создаёт конфиг |

Полезные опции:

```sh
diskblame snap ~ --exclude '*.log' --min-file-size 5MiB
diskblame diff --since 30d --path DCIM --limit 10
diskblame diff --files --limit 50
diskblame why ~/Downloads/archive.zip --no-refs
diskblame chart --days 90
diskblame prune --keep 20 --vacuum
diskblame watch --root ~ --since 7d --max-growth 1GiB --snap --interval 1h
```

Большинство команд принимают `--json` для скриптов.

## как это работает

Снапшот хранит:

- одну строку на каталог с общим размером, числом файлов и числом каталогов
- одну строку на файл от `min_file_size`, по умолчанию 1 миб
- метаданные снапшота: корень, время, общий размер, число файлов, число каталогов, время сканирования

Итоги каталогов включают все файлы, в том числе ниже порога. Порог ограничивает только отдельные файлы для `top --files`, `diff --files` и проверки дубликатов. `diff --files` показывает изменение размера, а не содержимого.

Жёсткие ссылки считаются один раз в итогах каталогов. Символические ссылки пропускаются, если не указан `--follow-symlinks`. Нечитаемые записи считаются и показываются, а не как ноль.

База по умолчанию лежит в `~/.local/share/diskblame/diskblame.db`. Снапшот нескольких сотен тысяч путей мал по сравнению с полной копией файлов.

## конфиг

Конфиг по умолчанию: `~/.config/diskblame/config.toml`. Создать его можно так:

```sh
diskblame config --init
```

Пример:

```toml
[scan]
exclude = [".git", ".hg", ".svn", "__pycache__", ".DS_Store", "lost+found"]
min_file_size = "1MiB"
follow_symlinks = false

[db]
path = "~/.local/share/diskblame/diskblame.db"
```

`--db` и `--config` переопределяют пути для одной команды.

## ограничения

- Хранит метаданные, а не содержимое файлов. Ничего не восстанавливает.
- Это не инструмент для бэкапов и не замена `du`, `ncdu` или `duc`.
- Размеры каталогов зависят от учёта блоков файловой системы. Разрежённые файлы могут показывать размер меньше видимой длины.
- Поиск дубликатов сравнивает сохранённые файлы одинакового размера, затем хеширует их. Для больших файлов используются первые и последние 1 миб плюс размер.
- Поиск ссылок использует `git grep` внутри репозитория и ограниченный скан текстовых файлов снаружи.
- `watch` работает в foreground. Запускай в tmux или через менеджер сервисов, если он должен жить постоянно.
